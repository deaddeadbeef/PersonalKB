## Pass 2 — Core Mechanics (~8 hours)

Re-read each page's ⚙️ Core Mechanics and 🏋️ Warm-Up sections. Understand the science and story mechanics in detail.

### Suggested order
Follow the same sequence as Pass 1 but shift focus from chapter summaries to the science and character domains. Spend extra time on:
- **Astrophage biology** — trace the real vs fictional biology boundary
- **Propulsion physics** — work through the mass-ratio problem
- **Xenolinguistics** — follow the communication progression step by step
- **Character arcs** — map Grace's amnesia arc and the Grace-Rocky friendship
- **Taumoeba solution** — trace the directed-evolution logic

### Checkpoints
After this pass you should be able to:
- [ ] Explain why Astrophage breaks known physics (and where it's grounded)
- [ ] Describe the Hail Mary's propulsion system and its limitations
- [ ] Trace the xenolinguistics progression from math to working language
- [ ] Explain the directed-evolution process that produces Taumoeba-82.5
- [ ] Articulate why Grace's final choice is the thematic climax

## Pass 4 — Practice (ongoing)

Build active-recall skill through drills and cross-referencing.

### Exercises
1. **Science check** — pick any five claims from the novel and trace them to the [[Science Accuracy Scorecard]]
2. **Timeline reconstruction** — reconstruct the dual timeline from memory (present chapters vs flashback chapters)
3. **Xenolinguistics replay** — list the communication milestones in order without referencing the arc page
4. **Ethics debate** — argue for and against Stratt's methods using evidence from the character notes
5. **Mass-ratio calculation** — work through the Hail Mary's fuel budget using the propulsion notes
