# Polaris Dawn Starlink Laser Comms Test

Polaris Dawn tested Starlink laser inter-satellite link communications using Crew Dragon as a non-Starlink relay node. The test transmitted data via optical inter-satellite links between Dragon and operational Starlink satellites, demonstrating cross-platform laser relay capability. This validated that crewed spacecraft can leverage the Starlink constellation for connectivity, supporting future deep-space communication architectures.
