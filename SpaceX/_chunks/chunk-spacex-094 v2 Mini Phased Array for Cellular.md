# v2 Mini Phased Array for Cellular

The Starlink v2 Mini satellites carry approximately 25 m² deployable phased arrays for direct-to-cell service. The link budget between a smartphone (~200 mW transmit power) and a satellite at 550 km is extremely constrained, requiring approximately 35–40 dBi antenna gain from the satellite. The phased array provides sufficient gain to close this link budget, enabling text messaging service with voice and data planned as capabilities improve.
