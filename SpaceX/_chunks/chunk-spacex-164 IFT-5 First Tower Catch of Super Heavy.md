# IFT-5 First Tower Catch of Super Heavy

IFT-5 (October 13, 2024) achieved the first-ever tower catch of the Super Heavy booster using the launch tower's "chopstick" mechanical arms. This milestone validated the core reusability architecture that underpins SpaceX's cost targets for Starship operations. IFT-4 had previously demonstrated both stages completing controlled splashdowns, and IFT-3 collected the booster splashdown data later used for the tower catch.
