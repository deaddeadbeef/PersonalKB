# Starship-as-Habitat Phase One

In Phase 1 of SpaceX's Mars base concept, landed Starships serve as the initial habitats. Each Starship provides pressurized volume with integrated life support, power distribution, and cargo storage — essentially a ready-made shelter upon landing. Multiple Starships landed in proximity create a small base cluster with redundant systems. This approach eliminates the need to develop, launch, and land separate habitat modules, though it constrains interior layout to Starship's cylindrical geometry. The initial outpost concept supports approximately 12 crew members.
