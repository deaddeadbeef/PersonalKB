# Falcon 9 Stage Acceptance Burns

Every Falcon 9 first stage undergoes a horizontal static fire acceptance test at McGregor with all nine Merlin engines firing simultaneously. This integrated stage-level test verifies propellant feed system operation, avionics function, thrust vector control response, and engine-to-engine interactions — failure modes that cannot be detected in individual engine tests alone. Additionally, Dragon thruster testing at McGregor covers both SuperDraco launch escape engines (~73 kN each) and Draco orbital maneuvering thrusters (400 N each).
