# Foundations — GRUB two-stage bootloader bridges firmware to kernel

## Context

GRUB (GRand Unified Bootloader) is the standard Linux bootloader. Its first stage fits in the MBR or EFI system partition and loads the larger second stage from the filesystem. The second stage parses `grub.cfg` (generated by `grub-mkconfig` from `/etc/grub.d/` scripts), presents a boot menu, and loads the kernel image and initial ramdisk into memory with a kernel command line containing parameters like root device and console settings.

## Why It Matters

The bootloader is the critical bridge between firmware and the OS. Understanding GRUB stages explains how boot problems are diagnosed, how dual-boot systems work, and why bootloader corruption can render a system unbootable even when the kernel is intact.
