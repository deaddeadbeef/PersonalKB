# Claude Sonnet 4 and Opus 4 Family

## Summary

Anthropic's Claude model family evolved rapidly from Claude 3.5 Sonnet (June 2024) through the Claude 4 series. Claude 3.5 Sonnet set new standards for coding and instruction following. The Claude 4 family introduced extended thinking (visible chain-of-thought reasoning), computer use capability (screenshot-based GUI interaction), and deep MCP integration. Opus 4.5 and Opus 4.6 represent Anthropic's most capable models, excelling at complex multi-step reasoning, coding, and agentic tasks.

## Key Claims

1. Extended thinking mode allows Claude to reason step-by-step with visible chain-of-thought
2. Computer use enables Claude to interact with graphical interfaces via screenshot analysis
3. MCP integration allows standardised connection to external tools and data sources
4. Safety training advances reduce harmful outputs while maintaining helpfulness
5. Claude Code (terminal agent) demonstrates Opus-class models can perform sustained autonomous coding

## Atomic Facts

1. Claude 3.5 Sonnet released June 2024
2. Claude 4 Sonnet released 2025
3. Claude Opus 4.5 and 4.6 are the most capable models as of early 2026
4. Extended thinking generates visible reasoning tokens
5. Computer use operates via screenshot→action loop at pixel coordinates
6. Claude Code uses Opus/Sonnet models as its reasoning engine

## Significance

The Claude 4 series demonstrated that safety-focused development does not preclude frontier capability, and that extended thinking and tool use can be combined to create highly capable autonomous agents.
