# GPT-5 Family

## Summary

OpenAI's GPT-5 series (5.1 through 5.4) unified the previously separate reasoning (o-series) and general-purpose (GPT-series) model lines into a single architecture. GPT-5 models combine strong reasoning, coding, multimodal understanding, and broad knowledge in one system. The series includes GPT-5.4 (flagship), GPT-5.3-codex (code-specialised), GPT-5.2, GPT-5.1, and GPT-5.4-mini/GPT-5-mini (cost-efficient variants). Native multimodal capabilities and improved instruction following characterise the family.

## Key Claims

1. GPT-5 unifies reasoning (o-series) and knowledge (GPT-series) into one architecture
2. Native multimodal processing eliminates the need for separate vision/audio models
3. Instruction following and factual accuracy are substantially improved over GPT-4
4. Codex variants are specialised for software engineering tasks
5. Mini variants offer similar capability profiles at significantly reduced cost

## Atomic Facts

1. GPT-5.1 through GPT-5.4 released progressively through 2025–2026
2. GPT-5.3-codex and GPT-5.2-codex are code-specialised variants
3. GPT-5.4-mini and GPT-5-mini are cost-efficient variants
4. Native multimodal: text, image, audio input processing
5. Available through ChatGPT and API
6. Represents unification of the o-series and GPT-series model lines

## Significance

The GPT-5 series resolved the fragmentation between reasoning and general-purpose models, establishing a unified approach that other labs have since followed.
