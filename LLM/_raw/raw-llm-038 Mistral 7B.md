# Mistral 7B

## What Is This?
A 7.3 B parameter open-weight language model that outperforms LLaMA 2 13B on all benchmarks and LLaMA 1 34B on many, using sliding window attention and grouped-query attention for efficient inference.

## Why It Matters
Demonstrated that careful architecture and training choices at smaller scale can match much larger models, making high-quality LLMs practical for local deployment. Its Apache 2.0 release catalyzed the open-source LLM ecosystem.
