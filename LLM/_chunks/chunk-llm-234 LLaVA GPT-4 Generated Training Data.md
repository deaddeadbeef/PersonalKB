# LLaVA Training Data Was Generated by GPT-4 from Image Metadata

LLaVA's multimodal instruction-following data was created by a clever bootstrapping approach: GPT-4 (text-only) received image captions and object bounding box annotations from the COCO dataset and was prompted to generate three types of instruction-following data. Multi-turn conversations (58K samples) simulate a user asking about image content. Detailed descriptions (23K) provide rich paragraph-level image descriptions. Complex reasoning (77K) requires multi-step visual reasoning.

Critically, GPT-4 never saw the actual images — it worked entirely from text metadata about the images. Despite this limitation, the generated data was diverse and high-quality enough to train LLaVA for genuine visual instruction following. This approach demonstrated that text-only LLMs can effectively bootstrap multimodal training data, a technique later adopted by LLaVA-1.5, ShareGPT4V, and other visual instruction tuning projects.
