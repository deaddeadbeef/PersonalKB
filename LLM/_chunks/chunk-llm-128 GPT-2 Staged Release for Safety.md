# GPT-2 Staged Release Was First LLM Safety Decision

OpenAI initially withheld the full 1.5B-parameter GPT-2 model in February 2019, citing concerns about potential malicious use for generating convincing disinformation. The model was released in stages over approximately 9 months (124M → 355M → 774M → 1.5B), making GPT-2 the first high-profile case of an AI lab restricting model release for safety reasons. This decision sparked a broad debate about open vs. closed release practices that continues to shape LLM deployment policy.
