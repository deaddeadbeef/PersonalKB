# Gemini Ships as Ultra, Pro, and Nano Variants

Gemini was released in three size variants targeting different deployment scenarios: Ultra (the largest, for highly complex reasoning and multimodal tasks), Pro (mid-size, for balanced performance and cost), and Nano (1.8B and 3.25B parameter versions, distilled for on-device deployment on mobile phones). This tiered release strategy — a single model family spanning data center to edge — became influential, with subsequent model families (LLaMA 3, Phi-3) also releasing multiple size variants targeting different compute budgets.
