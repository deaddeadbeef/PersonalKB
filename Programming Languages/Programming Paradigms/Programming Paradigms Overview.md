# Programming Paradigms Overview

A programming paradigm is a fundamental approach to structuring computation. It determines how programmers conceptualize problems, organize solutions, and compose abstractions. While modern languages are multi-paradigm, understanding the pure paradigms reveals the design principles each language prioritizes.

## The Major Paradigms

| Paradigm | Core Idea | Key Languages |
|----------|-----------|---------------|
| Imperative | Sequences of state-changing commands | C, Go, Zig |
| Object-Oriented | Encapsulated state + behavior in objects | Java, C#, Ruby, Smalltalk |
| Functional | Pure functions, immutable data, composition | Haskell, OCaml, Erlang, Lisp |
| Logic | Declarative rules and unification | Prolog, Datalog, miniKanren |
| Concatenative | Function composition as the primary operation | Forth, Factor |

## The Paradigm as Lens

Each paradigm is a lens for viewing computation:
- **Imperative:** Computation is a sequence of instructions modifying state. Think of a recipe.
- **OOP:** Computation is objects sending messages to each other. Think of a simulation.
- **Functional:** Computation is applying and composing functions. Think of mathematics.
- **Logic:** Computation is searching for solutions satisfying constraints. Think of puzzles.

No paradigm is universally superior — each excels at different problem types. The history of PL design is largely the story of mixing paradigms to handle diverse real-world requirements.
