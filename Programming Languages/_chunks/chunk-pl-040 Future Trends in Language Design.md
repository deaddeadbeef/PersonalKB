# chunk-pl-040 Future Trends in Language Design

**Gradual typing everywhere:** TypeScript proved it works. Python type hints spreading. Ruby Sorbet. The static/dynamic debate dissolves into a spectrum.

**Algebraic effects:** OCaml 5 and Koka represent the next evolution. Effects subsume exceptions, async/await, generators into one user-definable mechanism.

**Ownership beyond Rust:** Swift ownership annotations, Mojo (Python-like + ownership). Compile-time memory safety is too valuable to be Rust-exclusive.

**Compile-time everything:** Zig comptime, C++ constexpr, Rust const expansion. The same language for compile-time and runtime. Compilers decide what happens when.

**WebAssembly as universal runtime:** Portable, sandboxed, near-native. Languages compiling to Wasm gain universal deployment. May fulfill Java's "write once, run anywhere" more broadly.

**Language convergence:** Rust adds async, Go adds generics, Java adds records + patterns, Python adds types. What remains distinctive: defaults (immutable vs mutable), runtime model (GC vs ownership), and ecosystem.

**AI-assisted development:** Languages easy for LLMs to generate (consistent syntax, strong types for validation) gain adoption advantages. Rust: compiler catches AI mistakes. TypeScript: types guide generation.
