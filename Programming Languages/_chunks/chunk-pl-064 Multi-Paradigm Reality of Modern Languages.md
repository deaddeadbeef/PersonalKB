# chunk-pl-064 Multi-Paradigm Reality of Modern Languages

No modern language is single-paradigm. The question: which paradigm is default, how easily can you reach others?

**Rust:** Imperative foundation with heavy functional features (iterators, closures, pattern matching, immutability-by-default). No OOP inheritance. Often described as "imperative with functional soul."

**Kotlin:** OOP (Java heritage) with strong functional features (data classes, sealed classes, lambdas, collection operations). Balanced between paradigms.

**Python:** OOP (class-based) with functional features (comprehensions, lambda, functools) and procedural style. Use whatever fits the problem.

**OCaml:** Functional-first with imperative escape hatches and optional (rarely used) OOP. The module system is the primary abstraction mechanism.

**Scala:** Most explicitly multi-paradigm — full OOP + full functional, deeply integrated. Shows both the power and complexity of genuine multi-paradigm design.

**JavaScript:** Prototype OOP + functional (closures, array methods) + imperative. The most paradigm-flexible mainstream language.

Convergence: every language is adopting FP features. What distinguishes languages is which paradigm the community and idioms favor.
