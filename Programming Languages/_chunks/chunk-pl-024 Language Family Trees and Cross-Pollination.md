# chunk-pl-024 Language Family Trees and Cross-Pollination

**C family (syntax):** C -> C++ -> Java -> C# -> Kotlin; C -> JavaScript -> TypeScript; C -> Go; C -> Rust (syntax only). Nearly every popular language uses C-derived syntax.

**ML family (type system):** ML -> OCaml, Standard ML; ML -> Haskell; ML -> F#; ML -> Rust (type system, pattern matching); ML -> Swift (optionals, pattern matching).

**Lisp family:** Lisp -> Scheme -> Racket; Lisp -> Common Lisp; Lisp -> Clojure. Influenced JavaScript (closures, first-class functions).

**Smalltalk family (OOP):** Smalltalk -> Ruby; Smalltalk -> Self -> JavaScript (prototypes).

Modern languages are syntheses:
- **Rust:** C++ (systems) + ML (types) + Haskell (traits from type classes)
- **Kotlin:** Java (platform) + Scala (features) + C# (syntax)
- **Swift:** Objective-C (platform) + Rust (value types) + Haskell (generics)
- **Go:** C (simplicity) + CSP (concurrency) + Oberon (visibility)
