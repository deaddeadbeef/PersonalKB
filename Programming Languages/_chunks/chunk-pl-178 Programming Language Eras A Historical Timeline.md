# Programming Language Eras A Historical Timeline

Programming languages evolved through distinct eras, each defined by the dominant problems of its time.

## Era 1: Machine and Assembly (1940s-1950s)
- **Problem:** Talking to hardware
- **Innovation:** Abstraction from binary

## Era 2: Scientific and Business Computing (1950s-1960s)
- **Languages:** Fortran (1957), COBOL (1959), Lisp (1958)
- **Problem:** Scientific computation and data processing
- **Innovation:** High-level languages, compilers, garbage collection

## Era 3: Structured Programming (1960s-1970s)
- **Languages:** C (1972), Pascal (1970), Smalltalk (1972)
- **Problem:** Managing growing program complexity
- **Innovation:** Structured control flow, type systems

## Era 4: Object-Oriented Revolution (1980s-1990s)
- **Languages:** C++ (1979), Java (1995), Python (1991)
- **Problem:** Reusable, maintainable large-scale software
- **Innovation:** Classes, inheritance, polymorphism

## Era 5: Internet and Web (1995-2010)
- **Languages:** JavaScript (1995), PHP (1995), C# (2000), Go (2009)
- **Problem:** Web applications, distributed systems
- **Innovation:** JIT compilation, web frameworks

## Era 6: Safety and Concurrency (2010-2020)
- **Languages:** Rust, Kotlin, Swift, TypeScript
- **Problem:** Memory safety, concurrency, type safety at scale
- **Innovation:** Ownership systems, null safety, async/await

## Key Insight
Each era's languages solved the dominant problem of their time. The current era (safety + concurrency) produced Rust and Kotlin.
