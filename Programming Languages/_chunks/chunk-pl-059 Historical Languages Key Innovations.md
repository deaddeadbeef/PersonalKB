# chunk-pl-059 Historical Languages Key Innovations

**Fortran (1957):** Proved compiled code can match hand-written assembly. First compiler. Introduced: expressions, subroutines, arrays. Modern Fortran still dominates scientific computing.

**COBOL (1959):** Business computing. English-like syntax. Records (named fields). Billions of lines still run banking/government systems.

**Simula (1967):** Invented classes, objects, inheritance, virtual methods. Direct ancestor of Smalltalk and C++.

**Smalltalk (1972):** Pure OOP — everything is an object, message passing, live coding. Invented the modern IDE. Influenced: Java, Ruby, Python, JavaScript (via Self).

**ML (1973):** Invented: Hindley-Milner type inference, algebraic data types, pattern matching, module system with abstract types. Ancestor of: OCaml, Haskell, F#. Influenced: Rust, Swift, Kotlin.

**Prolog (1972):** Logic programming. Unification and backtracking. Influenced SQL, type inference, pattern matching.

**APL (1962):** Terse mathematical notation for arrays. Influenced NumPy, MATLAB, R, Julia.

Pattern: each language solved a specific problem. Their innovations became universal features we now take for granted.
