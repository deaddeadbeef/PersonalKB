# chunk-pl-023 Language Eras and Evolution

**1950s Pioneers:** Fortran (first compiler, 1957), LISP (first functional, invented GC, 1958), COBOL (business computing, 1959).

**1960s Structure:** ALGOL 60 (syntax ancestor of nearly all languages), Simula 67 (invented OOP).

**1970s Systems and Theory:** C (1972, Unix), Smalltalk (pure OOP), ML (type inference, ADTs), Prolog (logic programming), Scheme (lexical scope).

**1980s Industrial:** C++ (1985), Erlang (1986, fault tolerance), Objective-C.

**1990s Internet:** Python (1991), Java (1995), JavaScript (1995), Ruby (1995), Haskell (1990), OCaml (1996).

**2000s Modern:** C# (2000), Go (2009), Scala, Clojure, D.

**2010s Safety:** Rust (2015), Kotlin (2016), Swift (2014), TypeScript (2012), Elixir (2011), Zig (2016).

Pattern: each era responds to the previous era's problems. C++ responded to C's lack of abstraction. Java responded to C++'s complexity. Rust responded to C/C++'s unsafety. Go responded to C++'s build times.
