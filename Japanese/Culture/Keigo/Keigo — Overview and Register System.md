# Keigo — Overview and Register System

敬語 (keigo) is the Japanese honorific speech system. It's not optional — misusing register is a social error.
![[nontbl-034-keigo.mp3]]

## Three Branches

| Japanese | Name | Function | Direction | Audio |
| ---------- | ------ | ---------- | ----------- | --- |
| 尊敬語 | Sonkeigo | Honorific | Elevates the OTHER person | ![[gap-002-phrase.mp3]] |
| 謙譲語 | Kenjōgo | Humble | Lowers YOURSELF | ![[gap-003-phrase.mp3]] |
| 丁寧語 | Teineigo | Polite | Neutral politeness (です/ます) | ![[gap-004-phrase.mp3]] |

## When to Use Each

| Situation | Register | Audio |
| ----------- | ---------- | --- |
| Talking about your boss's actions | Sonkeigo |
| Describing YOUR actions to a client | Kenjōgo |
| General polite conversation | Teineigo |
| Talking to close friends | Plain (タメ口) | ![[gap-005-Plain-().mp3]] |

## The Key Insight
Keigo is about RELATIONSHIPS, not formality:
- **Uchi (内)** — In-group → speak humbly about
![[nontbl-038-uchi.mp3]]
- **Soto (外)** — Out-group → speak honorifically about
![[nontbl-039-soto.mp3]]

Your boss is uchi when talking to a client (so you use humble forms for your boss!).

## Common Mistakes
1. Using sonkeigo for yourself (sounds arrogant)
2. Using kenjōgo for others (sounds rude)
3. Double-keigo: ○ お読みになる ✗ お読みになられる
