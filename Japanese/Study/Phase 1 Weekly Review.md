# Phase 1 Weekly Review

> Use this once per week during [[Phase 1 — Foundation]]. The point is to keep the study system honest: what happened, what slipped, what audio was repeated, and what to do next.

## How To Use This Note

Create a dated copy or paste the sections into your own study log each Sunday. Keep it short. The review should take 10-20 minutes, not become another homework assignment.

The review has one job: choose the next small action. If reviews piled up, reduce new cards. If kana is still slow, keep drilling kana. If grammar feels vague, reread the current grammar page and write your own examples before moving forward. If the audio evidence is vague, keep the same native segment and local clip set for another week. When the review is complete, add one summary row to [[Authentic Audio Evidence Log]].

## Decision Rules

Use these rules to decide whether to advance:

| Signal | Decision |
| --- | --- |
| Reviews took more than 20 minutes most days | Add fewer new cards next week |
| Hiragana or katakana still requires chart lookup | Stay with kana drills |
| Grammar examples feel readable but not producible | Make 5 new sentences from the same frame |
| Listening feels like noise | Use shorter audio and repeat the same clip |
| You cannot name the exact native segment repeated | Return to [[Phase 1 Authentic Audio Spine]] and choose one stable source |
| Local clip and native model disagree | Treat the local clip as suspect until checked through [[Pronunciation and Audio Accuracy]] |
| Self-introduction is still hesitant | Practice the same script daily before expanding it |
