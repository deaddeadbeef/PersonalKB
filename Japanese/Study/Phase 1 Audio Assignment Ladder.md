# Phase 1 Audio Assignment Ladder

> Use this for all four weeks of [[Phase 1 — Foundation]]. The job is to keep each week tied to one authentic segment, one local drill set, one comparison target, and one proof row.

## How To Use

1. Use [[First Month Japanese Study Plan]] as the week-to-week execution path.
2. Start Week 1 with [[Phase 1 Audio Starter Assignment]].
3. Keep the same primary authentic source for all of Phase 1 unless it clearly fails.
4. At the start of each week, copy the matching assignment row into [[Authentic Audio Evidence Log#Current Assignment]].
5. Run [[Daily Audio Loop]] on each study day.
6. At the end of the week, fill [[Phase 1 Weekly Review]] and add one summary row to [[Authentic Audio Evidence Log]].

Do not add extra resources because a week feels easy. Repeat, shadow, and compare more precisely.

## Advancement Rule

Move to the next week only when the current row has real evidence:

- the authentic source and segment are named;
- the local clip set was repeated on at least three days;
- one short segment was shadowed aloud;
- one pronunciation, rhythm, pitch, reading, or register feature was checked;
- normal proof was recorded in [[Authentic Audio Evidence Log]];
- suspect local clips, if any, were recorded in [[Pronunciation Correction Log]].

If any item is missing, repeat the same assignment next week with a shorter authentic segment.
