# Phase 3 Weekly Review

> Use this once per week during [[Phase 3 — Expansion]]. The point is to prove that N4 grammar, 1000-word listening, pitch awareness, and intermediate input are becoming usable in heard and spoken Japanese.

## How To Use This Note

Create a dated copy or paste the sections into your own study log each Sunday. Keep it short enough to finish in 15-25 minutes.

At the start of the week, copy the current block from [[Phase 3 Audio Assignment Ladder]] into [[Authentic Audio Evidence Log#Current Assignment]]. For Block 1, use [[Fourth Month Japanese Study Plan]] as the daily execution path. For Block 2, use [[Fifth Month Japanese Study Plan]]. For Block 3, use [[Sixth Month Japanese Study Plan]]. For Block 4, use [[Phase 3 Block 4 Japanese Study Plan]]. Phase 3 review should name one exact authentic segment, one local clip set, one pitch or reading check, and one output or shadowing proof. If the week was mostly silent reading, the audio loop did not happen. When the review is complete, add one summary row to [[Authentic Audio Evidence Log]].

## Phase 3 Decision Rules

| Signal | Decision |
| --- | --- |
| Authentic audio became passive background | Shorten the segment and require shadowing or transcription |
| You cannot name the exact segment repeated this week | Return to [[Phase 3 Authentic Audio Spine]] and choose one stable source |
| Pitch accent claims rely on local TTS alone | Check [[Pronunciation and Audio Accuracy]] with OJAD, NHK, Forvo, course audio, tutor feedback, or native audio |
| N4 grammar is readable but not speakable | Repeat fewer examples and produce three sentences aloud |
| Kanji vocabulary is disconnected from sound | Return to spoken words before adding isolated characters |
| Media or songs became random immersion | Choose one short replayable segment with text, subtitles, lyrics, or lesson context |
| A local clip sounds wrong | Record it in [[Pronunciation Correction Log]] before it goes back into daily practice |

## Phase 3 Exit Check

Do not move to [[Phase 4 — Intermediate Mastery]] until the [[Phase 3 — Expansion|Phase 3 checkpoint]] is true and the audio evidence is real:

- [ ] You have repeated a stable Phase 3 authentic audio source for multiple weeks
- [ ] You can use [[Phase 3 Audio Assignment Ladder]] to choose the current block without improvising
- [ ] You can use [[Phase 3 Local Audio Practice]] to find the right local block without searching the whole vault
- [ ] You can pair each required Phase 3 page with audio using [[Phase 3 Audio Coverage Map]]
- [ ] You can shadow one short intermediate segment without reading every word
- [ ] You can check a pitch, accent, or reading uncertainty through [[Pronunciation and Audio Accuracy]]
- [ ] You can reuse N4 grammar and Core 1000 vocabulary aloud in short sentences
- [ ] You have opened [[Phase 4 Authentic Audio Spine]], [[Phase 4 Audio Assignment Ladder]], [[Phase 4 Audio Coverage Map]], and [[Phase 4 Weekly Review]] before starting Phase 4 content
- [ ] Suspect local clips stay out of daily practice until checked or recorded in [[Pronunciation Correction Log]]
