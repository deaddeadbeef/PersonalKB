# Phase 5 Weekly Review

> Use this once per week during [[Phase 5 — Advanced]]. The point is to prove that advanced Japanese is becoming usable through native-source listening, output, register control, and pronunciation or pitch checks.

## How To Use This Note

Create a dated copy or paste the sections into your own study log each Sunday. Keep it short enough to finish in 20-30 minutes.

At the start of the week, copy the current block from [[Phase 5 Audio Assignment Ladder]] into [[Authentic Audio Evidence Log#Current Assignment]]. For Block 1, use [[Eleventh Month Japanese Study Plan]] as the daily execution path. For Block 2, use [[Twelfth Month Japanese Study Plan]] as the daily execution path. For Block 3, use [[Thirteenth Month Japanese Study Plan]] as the daily execution path. For Block 4, use [[Fourteenth Month Japanese Study Plan]] as the daily execution path.

Phase 5 review is not a passive immersion diary. Each week should identify one exact native source segment, one local drill target from [[Phase 5 Local Audio Practice]] or the current page, one output attempt, and one pronunciation, pitch, reading, register, or naturalness check. When the review is complete, add one summary row to [[Authentic Audio Evidence Log]].

## Phase 5 Decision Rules

| Signal | Decision |
| --- | --- |
| Native audio is mostly passive background | Shorten the segment and require shadowing, transcription, or summary |
| You cannot name the exact segment repeated this week | Return to [[Phase 5 Authentic Audio Spine]] and choose one stable source |
| Local clips are easier than native audio, so native audio gets skipped | Keep local clips to 3-5 minutes and make native audio the main block |
| Keigo or business phrases feel memorized but socially risky | Record the phrase in [[Advanced Output and Register Feedback Log]] and get human/native feedback |
| Pitch or reading uncertainty repeats | Check [[Pronunciation and Audio Accuracy]] and log clip-quality issues in [[Pronunciation Correction Log]] |
| JLPT practice improves but real listening does not | Pair JLPT listening with native input on the same topic |
| Output is avoided for more than two weeks | Make one 30-60 second recording before adding new input |

## Phase 5 Stability Check

Do not treat Phase 5 as stable until these are true:

- [ ] You can sustain one native-source segment across multiple days
- [ ] You can use [[Phase 5 Audio Assignment Ladder]] to choose the current block without improvising
- [ ] You can use [[Phase 5 Local Audio Practice]] without hunting through page-level clips
- [ ] You can pair each required Phase 5 page with audio using [[Phase 5 Audio Coverage Map]]
- [ ] You have at least one recurring output or register feedback route
- [ ] You can summarize or shadow a short native segment without relying on English
- [ ] You can explain why a keigo, business, idiom, pitch, or discourse-marker choice is natural in context
- [ ] Suspect local clips stay out of daily practice until checked or recorded in [[Pronunciation Correction Log]]
