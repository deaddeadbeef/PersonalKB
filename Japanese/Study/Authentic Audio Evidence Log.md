# Authentic Audio Evidence Log

> Use this page to keep the authentic-audio habit accountable across weeks. Weekly review pages prove the current week; this log preserves the running trail.

## Rule

Add one row at the end of each weekly review. The row must name a replayable authentic source segment, the local clip set it supported, and the pronunciation or register check you made.

If the exact segment is blank, the week does not count as authentic-audio proof.

## Valid Evidence

Use this when deciding whether a row is strong enough.

| Evidence type | Strong row | Weak row |
| --- | --- | --- |
| Source | `Genki I Lesson 1 Dialogue A, pause version` | `Genki audio` |
| Segment | `NHK Easy Japanese Lesson 3 skit, first exchange` | `NHK` |
| Local clips | `Phase 1 Local Audio Practice Week 1, long vowels + は/へ/を` | `audio clips` |
| Pronunciation check | `Compared long vowel in こうこう against course audio` | `pronunciation` |
| Output | `Shadowed こんにちは。私は... without reading` | `speaking practice` |
| Decision | `Repeat same segment; small っ still weak` | `continue` |

## Phase Prompts

| Phase | Minimum evidence |
| --- | --- |
| Phase 1 | One beginner course/NHK/tutor segment, one Phase 1 local clip set, and one kana/particle/timing check |
| Phase 2 | One N5 dialogue or task segment, one Phase 2 local clip set, and one particle/verb/counter/kanji-reading check |
| Phase 3 | One transcripted intermediate segment, one Phase 3 local block, and one pitch or reading check |
| Phase 4 | One native-speed or official-course segment, one Phase 4 local block, and one register/keigo/rhythm check |
