# Phase 3 Pitch Accent Practice Path

> Use this during [[Phase 3 — Expansion]] after [[Pitch Accent — Introduction]] and [[Pitch Accent — Common Patterns]]. The goal is not perfect native pitch; it is to stop treating local TTS as the pitch authority and to build a repeatable accent-check habit.

## Source Rule

Use sources in this order:

| Need | Use first | Use local clips for |
| --- | --- | --- |
| Word pitch decision | OJAD, NHK accent dictionary, Forvo, course audio, tutor feedback, or native speaker recording | Awareness and recall after checking the source |
| Minimal-pair contrast | Dictionary/native reference plus the local minimal-pair clips on [[Pitch Accent — Introduction]] and [[Pitch Accent — Common Patterns]] | Repeating the contrast in Obsidian |
| Sentence rhythm | [[Phase 3 Authentic Audio Spine]] or tutor/native recording | Repeating one checked sentence after hearing a human model |
| Conflicting sources | [[Pronunciation and Audio Accuracy]] and, if the local clip itself is suspect, [[Pronunciation Correction Log]] | Nothing until the disagreement is resolved |

Local pitch clips are drills, not the referee.

## Daily Five-Minute Loop

Use this only after the normal Phase 3 audio pairing is clear in [[Phase 3 Audio Assignment Ladder]]. When Block 4 is active, use [[Phase 3 Block 4 Japanese Study Plan]] to keep pitch checks tied to one repeatable authentic segment and weekly proof.

1. Pick one word or minimal pair from the current Phase 3 page.
2. Check the accent pattern in OJAD, NHK, Forvo, course audio, tutor feedback, or a native recording.
3. Play the matching local clip from [[Pitch Accent — Introduction]] or [[Pitch Accent — Common Patterns]] only as a repetition drill.
4. Say the word with one particle or short sentence, then compare it to the native or dictionary source again.
5. Record one line in [[Phase 3 Weekly Review]]: word, source checked, pattern noticed, and what to repeat.

Do not add more than five pitch items in a day. Pitch practice should sharpen listening, not turn Phase 3 into dictionary browsing.

## Four-Week Path

| Week | Focus | Source check | Local drill | Proof |
| --- | --- | --- | --- | --- |
| 1 | Hear the four pattern names | Check one example each for heiban, atamadaka, nakadaka, and odaka | Pattern clips on [[Pitch Accent — Introduction]] | Explain where the drop happens |
| 2 | Minimal pairs | Check two minimal pairs in a dictionary/native source | Minimal-pair clips on the pitch pages | Hear and repeat one contrast |
| 3 | Current vocabulary | Check five words from [[Core 1000 — Conversational Fluency]] or the current N4 page | Page clips only after source check | Add pitch notes to cards or review notes |
| 4 | Sentence rhythm | Use one repeatable segment from [[Phase 3 Authentic Audio Spine]] | Repeat only the words you checked | Shadow one sentence and log the pitch issue |

## Card Rule

Only add a pitch note to a card when you can name the source you checked.

| Card field | Minimum |
| --- | --- |
| Word | Japanese spelling and reading |
| Accent | Pattern name or drop position if checked |
| Source | OJAD, NHK, Forvo, course audio, tutor, or native segment |
| Audio | Native/course source first; local clip only as secondary drill |
| Review note | One short sentence or particle environment |

## When To Stop

Stop the pitch drill and return to normal Phase 3 listening when:

- The source check takes longer than the listening block.
- You are memorizing symbols without hearing the word.
- A local clip and reference source disagree.
- The word has dialect, register, name, or context complications you cannot verify yet.

Record clip-quality problems in [[Pronunciation Correction Log]]. Record normal learner corrections in [[Phase 3 Weekly Review]].
